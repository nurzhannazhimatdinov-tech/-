# Танчики Онлайн

Многопользовательская браузерная игра в танчики (в духе Battle City): Node.js + WebSocket на сервере, Canvas в браузере.

## Запуск

```bash
npm install
npm start
```

Откройте http://localhost:3000. Друзья в той же Wi‑Fi сети заходят по адресу, который сервер выводит в консоль (`http://192.168.x.x:3000`).
Порт можно поменять: `PORT=8080 npm start`.

## Игра через интернет

- Быстро: `npx localtunnel --port 3000` или `ngrok http 3000` — и отправьте ссылку друзьям.
- Постоянно: задеплойте папку на Render / Railway / любой VPS (команда запуска `npm start`, порт берётся из `PORT`).

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Пробел | огонь |
| Enter | чат |
| M | звук вкл/выкл |

На телефоне появляются виртуальный джойстик и кнопка огня.

## Что есть

- Авторитетный сервер (60 тиков/с), клиентская интерполяция — без читов с позицией.
- Случайная симметричная карта: кирпич (разрушается и восстанавливается), броня, вода, кусты (в них прячутся).
- Бонусы: ремонт, щит, скорострельность, ускорение.
- Боты добавляются автоматически, если людей меньше 6.
- Таблица лидеров, лента убийств, чат, миникарта, звуки, эффекты взрывов.
